Banners da home

O carrossel no topo da página inicial. A ordem aqui é a ordem em que aparecem.

Sobre as imagens: suba os arquivos em assets/img/banners/ com o mesmo nome base e quatro variações (-800.jpg, -800.webp, -1920.jpg, -1920.webp). O comando npm run otimizar-imagens gera as quatro a partir de uma foto grande.
